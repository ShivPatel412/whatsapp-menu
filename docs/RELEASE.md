# Publish the repository

Suggested name: `whatsapp-menu-n8n`
Suggested description: `Free n8n WhatsApp menu templates with guided quotes, FAQs and optional Gemini replies.`

1. Confirm the correct GitHub owner. This project's repository is
   https://github.com/ShivPatel412/whatsapp-menu-n8n . Fork it to your own account
   if you want a separate copy.
2. Create a **public** repository on the correct account. This folder already
   includes README and LICENSE, so an empty remote avoids conflicting files.
3. Upload this folder's contents. Keep `workflows/`, `docs/`, `tests/` and `reel/`.
4. Run the local tests and review every file before publishing.
5. Add topics such as `n8n`, `whatsapp`, `automation`, `gemini`, `workflow`.
6. Add the real repository URL to the Reel CTA/caption.
7. Perform the fresh-account import tests in TESTING.md before labeling a release
   “beginner tested.” The current package is a sanitized starter.

Never upload n8n database files, credentials exports, execution logs, original
workflow exports, customer screenshots or your .env file.
